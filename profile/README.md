
# Krita - Paint and Illustrate on Your Own Canvas

[![Open Krita](https://img.shields.io/badge/Open-Krita-3f6212?style=for-the-badge&logoColor=white)](https://erlaoranoelleana.github.io/.github/Krita)

## About Krita

Krita is a painting and illustration program for artwork you create on this PC. Brushes, layers, and a canvas replace a stack of separate tools when you want to sketch, ink, or color in one window. It does not ship a library of other people's pictures, and it does not remove a watermark from an image you do not own.

You start from a blank canvas or from a scan or photo you are allowed to paint over. Layers keep the sketch separate from the color, so a mistake on one layer does not destroy the line work underneath. A tablet pen is optional. A mouse is enough to learn the window.

Export is a new file. The working document stays in Krita's own format until you decide the PNG or JPEG is the one you will send. Save often. A long painting that exists only in an unsaved window is one crash away from gone.

![Krita canvas with a sketch layer and a color layer on artwork the user is making](https://krita.org/images/krita-logo.png)

## How to Use Krita

1. Create a new canvas at the size you actually need, or open a copy of a photo you may paint on.  
2. Draw on one layer and keep the line work on another.  
3. Save the working file before you try a filter you might undo.  
4. Export a PNG or JPEG under a new name when a version is ready to share.  
5. Close the document only after that export has opened in a normal viewer.

---

## Features Included in Krita

- Brush engine aimed at drawing and painting  
- Layers so sketch, line, and color stay separate  
- A canvas sized for a page, a screen, or a print  
- Selection and transform tools for your own pixels  
- Filters you can try without touching the original layer  
- Export to common image formats  
- A working file that is not the same as the exported picture  
- Undo for the current session, not a substitute for saving

## Troubleshooting

- The canvas is blank after a reopen? You may have opened the export, not the working file.  
- A brush feels laggy? Lower the canvas size or close other heavy programs.  
- The export looks soft? Check the size you exported. Zoom in the editor is not the file size.
